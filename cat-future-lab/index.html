01

系統架構

網站分成畫面層、狀態層、資料層與素材層。每個互動都先進入 AppState 或 Action Router，再由 UI 依狀態更新。

SPA左右切換頁面
StateCookie 保存偏好
Proxy金鑰留在 server
  • config.js 管理 pageMap、主題 token、背景 preset 與說明文字。
  • state.js 集中保存主題、背景、字體、頁面、形狀與簡報模式。
  • aiActions.js 負責解析、驗證與執行安全 action。
02

視覺與資產管線

貓咪素材只作為品牌記憶與觀測輔助，主軸仍是城市資料與互動控制。游標、主視覺與天氣圖都採動畫風格。

資產策略

  • 圖片以本機檔案供應，避免外部載入延遲。
  • 像素游標是透明 PNG，JS 只負責定位。
  • 影片有 poster fallback，沒有 render 檔也能閱讀摘要。
03

動畫層分工

動畫被拆在不同模組：Anime.js 管理進場節奏，Three.js 管理 canvas 場景，GSAP 只保留低成本指標與 hover 效果。

Anime.js

  • Hero 文字進場。
  • 數字動畫與區塊 reveal。
  • 以 transform / opacity 為主。

GSAP

  • SPA 模式下關閉 ScrollTrigger 類效果。
  • 保留輕量 hover tilt。
  • 低效能時可完全降級。
04

3D 訊號場域

3D 區域像平台的即時觀測窗，以幾何、粒子與光照模式暗示不同城市訊號狀態。

  • 穩定模式：適合靜態觀測與閱讀。
  • 動態模式：強化粒子速度與視覺活性。
  • 專注模式：降低干擾，凸顯核心訊號。
  • 文字摘要保留資訊，不讓內容只存在 Canvas。
05

城市資料面板

城市資料面板讓使用者選擇不同地點，快速查看當地時間、溫度、風速與資料來源。

  • 城市清單涵蓋台灣與國際主要城市。
  • 每個城市保留自己的時區顯示。
  • 資料失敗時仍保留狀態說明，不讓平台看起來斷線。
06

快速導覽與 API Proxy

導覽員可回答功能怎麼做，也可把自然語言轉成安全 action。真實模型請求走 server proxy，前端不接觸金鑰。

資料安全

  • 金鑰只存在 server 環境變數。
  • 模型請求統一走 proxy。
  • 上游失敗時回到安全回覆。

控制能力

  • 切換頁面、主題、背景、字體與形狀。
  • 修改跑馬燈與簡報模式。
  • 可還原上一個安全設定。
07

Remotion 影片素材

Remotion 用 React frame timeline 產出輔助影片；主網站不依賴 render 成功，影片缺失時仍可用 poster 與文字摘要。

08

主題、背景與可讀性

主題決定整體語言，背景與文字顏色則是可調整的表層設定。使用者改白色、黑色或 hex 色碼時，不會破壞原本主題。

Theme未來 / 溫暖決定整體語氣
Background支援 preset 與 #hex 色碼
Contrast自動選擇可讀文字色

導覽可以改什麼

  • 背景改成黑色、白色、粉紅、奶油色或 #111827。
  • 文字顏色可用合法色碼或常見顏色詞控制。
  • 方塊形狀由安全 Action Router 轉成預設視覺模式，避免任意 CSS 破壞版面。

安全規則

  • 背景控制不會改變已選主題。
  • 不執行模型回傳的任意 CSS 或 JavaScript。
  • 不明確的顏色或形狀指令會被回覆 unknown。
09

效能與可近用

互動效果以「可降級」為前提。低效能或 reduced-motion 環境會降低粒子、轉場與跑馬燈成本，核心功能不關閉。

SEOmeta / OG / JSON-LD
A11yKeyboard / Focus / Live
  • 桌面與手機都要避免文字重疊與控制遮擋。
  • 動態狀態使用 aria-live，表單與按鈕保留鍵盤操作。
  • 游標改為圖片定位，移除高頻 DOM 手臂動畫。
10

驗收重點

驗收集中在狀態安全、畫面可讀、API fallback 與簡報操作隔離，避免功能做出來但在真實操作時互相干擾。

  • 背景白色、黑色與色碼輸入都要保留文字對比。
  • 簡報滾輪不可帶動整個 SPA 頁面。
  • 無 API key 或上游失敗時仍有可理解回覆。
11

Action Schema 與安全邊界

導覽員可以用更彈性的自然語言理解需求，但不執行任意 JS；模型輸出會先正規化成 JSON Action，再由 Router 套用。

  • setBackground 只接受合法 hex 或 preset。
  • setShapeMode 會轉成系統已定義的形狀模式，不接受任意 CSS 字串。
  • 不允許 eval()、new Function() 或模型回傳 HTML 執行。
12

Action Router 與狀態同步

按鈕、鍵盤、滑動、輪軸與快速導覽全部走同一份狀態。這讓進度線、active nav、頁面與 cookie 偏好保持一致。

  • PageId：home、intro、features、tech、gallery、about、contact、presentation。
  • 切頁使用 transform 與 opacity，降低 layout reflow。
  • 導覽員保留上一個安全設定，支援「還原」回復上一動作。
