Final Report Structure

報告內容對齊範本，但案例與風格完全重做。

上台可照這四段說明，從設計動機、互動技術、API 安全一路到 SEO 與無障礙驗收。

  1. 設計理念貓咪是引導符號，不是整體造型；主視覺是互動動畫實驗室。
  2. 動畫技術CSS 負責基礎狀態，Anime.js 管 timeline/stagger，Three.js 管 3D/rAF。
  3. API 串接聊天走 server proxy；天氣 API 顯示 loading、success、fallback、error 狀態。
  4. SEO 與無障礙語意 HTML、JSON-LD、鍵盤操作、ARIA、對比、alt/text alternative 與 reduced motion。
