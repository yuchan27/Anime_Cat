Cat Future Lab

一個用貓咪作為導覽角色的互動動畫期末作品，將第十三週的 Anime.js 與 Three.js 技術整合成可展示、可操作、可報告的一頁式網站。

進入互動場景 詢問貓咪導覽員
MEOW SYSTEM ONLINE

互動式 3D 貓咪場景

滑鼠或觸控會影響貓咪視線、尾巴節奏與背景粒子。若使用者設定降低動態，場景會保留靜態視覺摘要並減少動畫。

動畫模組展示

每個模組都對應期末評分項目：技術層次、視覺設計、互動回饋與可重複使用的元件思維。

01

Anime.js 文字時間軸

使用 stagger、timeline 與 easing 建立標題入場、按鈕回饋與資訊節奏。

02

Three.js 空間角色

用幾何模型建立貓咪角色，讓 canvas 成為第一視覺訊號，而不是裝飾背景。

03

API 狀態面板

透過 Server Proxy 連接 AI 聊天，並以即時天氣資料改變畫面狀態。

04

Remotion 素材管線

用 React 影片專案產出可嵌入網站的短循環素材，支援報告展示。

AI 貓咪導覽員

聊天請求會送到本機 server proxy，由伺服器端讀取 Google AI Studio 金鑰。未設定金鑰時會回傳安全示範文字。

期末報告重點

報告時可以依序說明設計動機、技術拆解、API 安全、SEO 與無障礙驗收。

  1. 設計理念貓咪作為導覽角色，讓技術展示更有記憶點。
  2. 動畫技術CSS、Anime.js、Three.js、requestAnimationFrame 與 Intersection Observer 分工。
  3. API 串接Server Proxy 保護 Google AI Studio key，天氣資料展示非同步流程。
  4. SEO 與無障礙語意 HTML、JSON-LD、鍵盤操作、ARIA、對比與 reduced motion。
