城市訊號互動觀測台

Cat Future Lab 把城市資料變成可探索的動態場域

這是一個結合即時城市天氣、3D 訊號場、AI 導覽與動態影像的互動網站。 貓咪只作為溫和的觀測助手與介面訊號，讓資料探索更有辨識度但不搶走主軸。

視覺語氣

畫面維持產品網站的資訊密度，搭配動畫風角色素材，讓整體既有專業感，也保留溫度。

設計原則

  • 高對比字級與明確區塊邊界。
  • 圖片與影片都要能說明平台情境。

互動引擎

互動層被拆成不同責任：畫面節奏、滾動回饋、3D 更新與資料狀態各自維護，讓平台可以繼續擴充。

畫面節奏

  • 開場文字與區塊進場。
  • 訊號路徑與節點提示。
  • 輔助角色的局部動態。

閱讀回饋

  • 區塊一次性顯示後固定。
  • 卡片 hover 與微互動。
  • Hero 場域跟隨游標產生深度。
04

3D 訊號場域

3D 區域像平台的即時觀測窗，以幾何、粒子與光照模式暗示不同城市訊號狀態。

  • 穩定模式：適合靜態觀測與閱讀。
  • 動態模式：強化粒子速度與視覺活性。
  • 專注模式：降低干擾，凸顯核心訊號。
  • 文字摘要保留資訊，不讓內容只存在 Canvas。

城市資料面板讓使用者選擇不同地點，快速查看當地時間、溫度、風速與資料來源。

  • 城市清單涵蓋台灣與國際主要城市。
  • 每個城市保留自己的時區顯示。
  • 資料失敗時仍保留狀態說明，不讓平台看起來斷線。

11

AI 控制擴充目標

本次擴充不是重做網站，而是在既有內容上新增一層可被自然語言控制的互動系統。

  • 保留既有圖像、3D、城市資料與影像素材。
  • 把控制行為收斂成安全 JSON Action。
  • 讓使用者用一句話控制頁面、背景、字體與跑馬燈。
12

左右切換式 SPA

頁面以 pageMap 管理，不依賴垂直長頁滾動。導覽列、左右鍵、滑動、輪軸與智慧導覽員都讀同一份頁面資料。

  • PageId：home、intro、features、tech、gallery、about、contact、presentation。
  • 既有 section 透過 domId 對應，不需要刪掉原本內容。
  • 切頁只使用 transform 與 opacity，維持效能。
13

雙主題系統

主題代表整體視覺語言，背景代表可調整的表層色彩。兩者分離，避免改背景時破壞主題。

  • future：成熟科技產品感，低調光感與乾淨資訊層級。
  • cat：柔和動畫貓咪感，保留可愛元素但不影響閱讀。
  • Theme Token Map 集中管理主題色，不在元件內亂寫色碼。
14

CSS Root Variables

主題、背景、文字、邊框、動畫速度與字體比例都透過 root variables 同步到整個介面。

  • --bg-main 控制主背景。
  • --font-scale 控制全站字級比例。
  • --transition-theme 與 --transition-page 控制切換節奏。
15

背景 Preset 與色碼

背景控制支援 preset 與合法 hex color。若使用者說白色、粉紅色、奶油色，也會被轉成安全色碼。

  • 支援 #ffffff、ffffff、#111827 等格式。
  • 奇怪或不明確的顏色不會套用，避免誤改畫面。
  • 套用自訂背景時會自動選擇較可讀的文字顏色。
16

字體比例縮放

字體大小不是把所有文字設成同一個尺寸，而是以比例變數維持標題、內文、按鈕與導覽的層級。

  • 模式：特大、大、中、小。
  • 控制來源：按鈕或智慧導覽員自然語言。
  • 實作方式：更新 --font-scale。
17

輪軸式導覽

輪軸不是裝飾，它讀取 pageMap 產生節點，點擊後走同一個 Action Router 切換頁面。

  • active 狀態與目前頁面同步。
  • 手機版會改成橫向可滑動節點。
  • 與底部進度線和智慧導覽員共用狀態。
18

跑馬燈控制

跑馬燈用 CSS animation 呈現狀態提示，智慧導覽員可以透過 setMarquee action 直接更新文字。

  • 範例：跑馬燈改成歡迎來到我的網站。
  • 低效能模式會降低動畫速度或簡化動畫。
  • 內容以 textContent 更新，不執行 HTML。
19

Action Schema

所有控制都被限制在固定 action 清單，例如 goToPage、setTheme、setBackground、setFontSize、setMarquee。

  • 無效 action 會被 validator 拒絕。
  • PageId、Theme、FontSize、BackgroundPreset 都有 enum 限制。
  • AI 或 mock parser 不能產生任意 JS。
20

Action Router

Action Router 是唯一會改變 AppState 的入口。UI 元件、輪軸與智慧導覽員都透過它更新狀態。

  • goToPage 只接受已知 PageId。
  • setBackground 只接受 preset 或合法色碼。
  • downloadPpt 會切到簡報頁並觸發既有 PPT 匯出流程。
21

安全限制

導覽員不允許直接操作 DOM，不允許 eval，不允許執行 AI 回傳的 JavaScript，也不把 AI 回傳 HTML 當成介面插入。

  • 自然語言先被轉成 JSON Action。
  • Action 通過 validator 後才會被 Router 執行。
  • 回覆文字使用 textContent 顯示。
22

底部進度線

進度線由 pageIndex 與 pageMap.length 計算，使用 scaleX 填滿，不顯示百分比。

  • 第一頁進度接近 0。
  • 最後一頁完整填滿。
  • future 與 cat 主題有不同游標視覺。
23

效能保護

效能模式會參考 reduced-motion、裝置記憶體與手機寬度，必要時降低粒子、轉場與跑馬燈成本。

  • 低效能模式仍保留核心控制功能。
  • 頁面切換可退回簡單 fade。
  • 簡報頁、字體切換、背景控制照常運作。
24

RWD 與手機操作

手機版保留左右滑動、底部切頁、橫向輪軸與智慧導覽員輸入，避免變成難操作的長頁。

  • 輪軸節點改成水平滑動。
  • 字體切換與跑馬燈不遮住主要控制。
  • Presentation Page 保留可閱讀排版。
25

未來擴充

目前版本先以 mock parser 完成所有控制路徑。下一階段可把 /api/ai-navigator 串接 Gemini 2.5 Flash 或 Gemma4。

  • AI 端只輸出 JSON Action，不輸出自由 HTML 或 JS。
  • 可加入更多背景 preset、簡報小節控制與城市資料視覺化。
  • 仍以模組化、效能與安全為優先。
