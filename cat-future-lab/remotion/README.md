# Remotion Material Pipeline

This subproject generates optional signal-board video material for the main website.

## Commands

```bash
npm install
npm run studio
npm run render:loop
```

Rendered files should go to `../assets/remotion/` and are ignored by Git.
The main site already has `assets/remotion/cat-loop-poster.svg` as a fallback.
The loop should read as a future lab signal with cat-ear / cat-eye hints, not as a full cat character animation.
