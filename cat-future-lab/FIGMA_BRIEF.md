# Figma Design Brief: Cat Future Lab

## Goal
Create a high-fidelity one-page design for a final web animation project. The design should feel like a future interactive animation lab with cat elements as guide signals, not a full cat-themed page and not a copy of the week 12 template.

## Frames
- Desktop 1440px: full one-page layout.
- Mobile 375px: stacked responsive layout.
- Component board: buttons, focus states, module card, chat field, weather data row.

## Visual Direction
- Theme: lab console, signal board, data orbit, geometric cat-ear marks, cat-eye HUD, tail-like path motion.
- Palette: paper `#f7f2e4`, ink `#11131f`, moss `#dce86a`, cyan `#51d6d0`, coral `#f36f52`, violet `#7766d8`, clay `#8e5b44`.
- Typography: bold display headings, readable Traditional Chinese body text.
- Container model: full-width bands, strong borders, no nested cards.
- Figma sync page: `Implementation Sync` records the updated implementation direction.

## Required Sections
- Hero: `Cat Future Lab`, large lab identity, cat signal diagram, direct CTA to 3D scene and AI guide.
- Interactive Scene: large Three.js canvas area with abstract lab core, cat-ear signal hints, text alternative and three mode controls.
- Animation Modules: four repeated modules for Anime.js, Three.js, API, Remotion.
- AI Guide + Weather API: chat form and live weather panel.
- Remotion Material: poster/video area for generated loop material.
- Report Notes: design concept, animation technique, API, SEO/accessibility.

## Accessibility / SEO Notes
- Keep visible focus styles.
- Preserve semantic heading hierarchy.
- Include reduced-motion state concept.
- Keep color contrast WCAG AA or better.
